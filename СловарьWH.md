# Словарь

1. **Достижение** — Игровой элемент и награда, которую пользователь получает за выполнение определенных действий или регулярное обучение.
2. **Интервальное повторение** — Система эффективного обучения, при которой слова, которые пользователь запоминает хуже, предлагаются для повторения чаще, а хорошо изученные — реже.
3. **Карточка слова** — Персональная запись пользователя, которая создается после успешного распознавания и содержит фотографию объекта, английское слово, его перевод и пример использования.
4. **Нейросетевая модель** — Компонент системы, который анализирует загруженную фотографию, распознает изображенный предмет и возвращает его название.
5. **Персональный словарь** — Раздел приложения, в котором сохраняются, хранятся и управляются все созданные пользователем карточки.
6. **Серия дней обучения** — Статистический показатель регулярности занятий пользователя, отражающий непрерывное ежедневное использование приложения.
7. **Тематическая коллекция(альбом)** — Группировка слов внутри словаря, создаваемая пользователем для удобного распределения и поиска карточек (например, по темам).
8. **Короткая тренировка** — Короткая учебная сессия по сохраненным карточкам, во время которой пользователю демонстрируется его собственная фотография предмета, по которой нужно вспомнить английское слово.
9. **Юзер** — Альтернативное название пользователя системы.
10. **Язык интерфейса** — Язык, на котором предоставляется пользовательский интерфейс системы.
11. **Фильтр словаря** — Инструмент для фильтрации карточек по коллекции и уровню изученности.
