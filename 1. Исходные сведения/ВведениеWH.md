# Введение

**1. Цель**
Целью данного документа является описание архитектуры мобильного приложения Word Hunt. Приложение предназначено для изучения иностранных слов через распознавание реальных предметов окружающего мира с помощью фотографий.

**2. Область применения**
Приложение ориентировано на студентов, молодых специалистов, а также пользователей с начальным и средним уровнем английского языка. Оно предназначено для индивидуального использования с целью быстрого изучения лексики короткими сессиями и расширения словарного запаса.

**3. Технический контекст**
Система представляет собой мобильное приложение для операционной системы Android. Архитектура включает в себяh клиентскую часть, серверную часть и сервис нейросетевого распознавания. Компоненты системы спроектированы так, чтобы в будущем можно было заменять или улучшать нейросетевую модель без существенного изменения остальных частей.

**4. Основные функции**
- Распознавание объектов на фотографиях пользователя с помощью нейронной сети.
- Автоматическое предложение английского слова и его перевода(благодаря распознованию нейрсети).
- Создание персональных карточек, содержащих фотографию, слово, перевод и пример использования.
- Обучение(интервальное повторение) словам языка с использованием собственных фотографий пользователя.
- Отслеживание статистики прогресса и выдача достижений.

**5. Проблемы и ограничения**
Нейросеть может ошибаться при распознавании объектов, поэтому пользователь должен иметь возможность проверять и исправлять результат вручную. Кроме того, функции взаимодействия с нейросетевой моделью зависят от наличия подключения к сети.
